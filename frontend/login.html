Forgot your password?

Run one of these on the machine Boltarr runs on. It switches login off — no password needed:

  • Docker — docker exec boltarr reset-password
    Use your container's name if it isn't boltarr.
  • Unraid — Docker tab → Boltarr icon → Console → type reset-password
  • Without Docker — in the Boltarr folder:
    venv/bin/python -m backend.reset_password

Then reload this page — Boltarr opens without a password — and set a new one in Settings → 🔒 Login.
